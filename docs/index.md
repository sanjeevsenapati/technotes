## Why Lishes?

Lishes serves as a centralized repository for various shell scripts, catering to both routine and advanced system administration requirements. The project is built to share knowledge, promote efficiency, and contribute to the DevOps and Linux administrator community.

## Usage Quickstart

1. Grant execution permissions:
```bash
chmod +x <script_name>.sh
```

2. Execute desired script:
```bash
./monitoring/system_health_check.sh
```

Explore the documentation to learn more about each available utility script.
